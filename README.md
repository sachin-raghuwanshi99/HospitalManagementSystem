# Hospital Management System

A Java-based Hospital Management System developed using Java, JDBC, and MySQL to manage patient records, doctor profiles, and appointment scheduling.

## 🚀 Features

- Add and manage patient records
- View patient information
- Manage doctor profiles
- View available doctors
- Book appointments
- Check doctor availability
- Update reservation and patient details
- Delete records
- Perform CRUD operations
- MySQL database integration

## 🛠️ Tech Stack

- Java
- Java SE
- JDBC
- MySQL
- SQL
- Object-Oriented Programming

## 📂 Project Highlights

The application uses Java and JDBC to connect with a MySQL database and perform data operations efficiently. It follows object-oriented programming principles to keep the application structured and modular.

Prepared statements are used for database queries to improve security and help prevent SQL injection.

The appointment module includes doctor availability checks to help manage appointment scheduling and avoid conflicts.

## 🗄️ Database

The application uses MySQL for storing and managing:

- Patient records
- Doctor information
- Appointment details

JDBC is used to establish the connection between the Java application and the MySQL database.
